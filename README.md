# Career Evidence Workflow

一个不包含任何真实用户经历的通用求职 Skill。它可以读取使用者自己上传的经历库；如果使用者没有经历库，也可以从其简历、作品集、笔记、共享文档和口述材料中重新建立。

## 能做什么

- 建立或更新个人经历证据库；
- 导入经历库、简历和其他文件，先形成可核对的候选人资料；
- 解读岗位描述并判断匹配度；
- 先检查学历、毕业时间、工作许可、地点、年限等硬性门槛；
- 研究公司、行业、岗位、团队、核心产品、商业模式和用户画像；
- 形成候选人自己的行业理解、岗位理解、求职动机和职业规划；
- 在深度模式下整理同岗位面经并内化为证据要求；
- 建立逐句 JD—能力—交付物/KPI—个人证据—简历动作映射；
- 根据使用者自己的证据定制简历；
- 按目标市场、语言、格式和申请渠道调整输出。

## 隐私说明

此 Skill 不附带任何人的经历库、简历、共享文档链接、姓名、公司经历或其他个人材料。每位使用者应上传自己的经历库，或者授权 AI 根据自己的材料新建。不得把不同使用者的经历库合并或复用。

个性化 JD 分析开始前，Skill 会先根据使用者自己的资料形成候选人摘要，并区分原始事实、AI 推断和待确认信息。没有个人材料时，只能进行岗位本身的客观研究，不能生成虚假的匹配度、求职动机或职业规划。

## 安装

将整个 `career-evidence-workflow` 文件夹复制到 Codex 的 skills 目录，或把文件夹交给支持读取 Skill 的 Agent。保留 `SKILL.md`、`references/`、`agents/` 和 `LICENSE` 的相对目录结构。

## 使用示例

已有经历库：

```text
请使用 $career-evidence-workflow。这是我自己的经历库和目标 JD。请先检查经历库并形成候选人资料，再研究公司、行业、团队、核心产品、用户画像和岗位，最后完成 JD 映射与简历定制。
```

没有经历库：

```text
请使用 $career-evidence-workflow。我还没有经历库，请根据我上传的简历和材料先建立经历库与候选人资料，确认关键信息后再分析目标 JD。
```

只做快速匹配：

```text
请使用 Quick 深度分析这份 JD，先告诉我匹配度、证据缺口和简历修改方向，不需要完整公司与面经研究。
```

## 分析深度

- `Quick`：JD 解读、匹配判断、证据映射和简历动作；
- `Standard`：增加公司、行业、团队、岗位、核心产品、用户画像、行业与岗位理解、求职动机和职业规划；
- `Deep`：增加从业者信息及同岗位面经内化。

输出语言、目标市场、文件格式、页面长度、模块顺序、照片和版式均由使用者决定，不默认继承任何个人偏好。
